# 🚀 V7.2 Gemini God Mode 起動＆運用マニュアル

## ⚙️ フェーズ1：システムの起動（準備）

このシステムは「ローカルのPythonサーバー」と「Chrome拡張機能」の2つのエンジンで動く。

### 1. 究極防壁サーバー（Python）を立ち上げる
コマンドプロンプト（またはPowerShell）を開き、ハッキングしたいプロジェクトの絶対パスを指定してサーバーを起動しろ。

```powershell
# 基本コマンド
python C:\GeminiHack\server.py <プロジェクトの絶対パス>

# 実行例
python C:\GeminiHack\server.py C:\Users\watanabe\Documents\project\java-android-applied\answer\RecyclerView_advance_sample
```
> **✅ 成功サイン:** ターミナルに `🚀 V7.2 究極防壁サーバー (Windows Edition) 起動` と表示されればOKだ。この画面は開いたままにしておくこと。

### 2. Chrome拡張機能を読み込む
1. ChromeのURLバーに `chrome://extensions/` と入力して拡張機能ページを開く。
2. 右上の **「デベロッパー モード」** がONになっていることを確認。
3. 左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックし、`C:\GeminiHack\extension` フォルダを選択。
4. Geminiのチャット画面を開く（またはリロード ↻ する）。
> **✅ 成功サイン:** 画面右下に4つのカラフルな「ハッカーボタン」が出現すれば完全接続だ！

## 🔄 フェーズ2：基本ハッキング・ループ（使い方）

ボタンを使った基本の自動化ループだ。息をするようにコードを錬成しろ。

### 🟦 ステップA：プロジェクトの全貌を俺（Gemini）に食わせる
1. 画面右下の **青いボタン「🚀 コードをDLしてぶち込む」** を押す。
2. `gemini_context.txt` というファイルが爆速でダウンロードされる。
3. そのファイルをチャットの入力欄に **ドラッグ＆ドロップ** して送信！
*(※これで俺はお前のプロジェクトの全ファイルとツリー構造を1秒で完全把握する)*

### 💬 ステップB：俺に指示を出す
「〇〇の機能を追加して」「バグを直して」と普通にチャットで指示を出せ。俺が自動的に `// UPDATE: ...` や `// CREATE: ...` といった絶対パス付きのコードブロックを生成する。

### 🟩 / 🟧 ステップC：コードをローカル環境に直接インジェクション
俺がコードを出力し終わったら、以下のどちらかのボタンを押せ。人間がファイルをコピペして開く必要は一切ない！

* **🟧 オレンジボタン「💾 ローカルのみ保存」:**
  コードをローカルファイルに直接上書き・新規作成するだけ。他人のリポジトリ（Cloneしてきただけのアプリなど）や、まだGitにPushしたくない時に使う安全装置だ。
* **🟩 緑ボタン「📤 保存＆Git Push」:**
  コードをローカルに保存した後、裏で自動的に `git add` → `git commit` → `git push` まで全自動でキメる最強ボタン。お前のオリジナルプロジェクトの開発を超加速させる。

## 🖼️ 特別機能：画像のバイナリ・インジェクション

俺（Gemini）が生成したAI画像を、直接プロジェクトのフォルダに叩き込む魔法だ。

1. チャットで俺に「〇〇の画像を作って」と頼む。
2. 俺が画像を生成すると同時に、保存先パス（例: `// IMAGE_PATH: app\src\main\res\drawable\icon.png`）を出力する。
3. チャット上の生成された画像を **右クリックして「画像をコピー」** する。
4. 画面右下の **黄色ボタン「🖼️ 画像をぶち込む」** を押す。
5. （Git Pushするかどうかのダイアログが出るので選ぶ）
*(※これで画像がBase64変換を通って、お前の指定したアセットフォルダに実体ファイルとして錬成される！)*

## ⚠️ 注意事項・トラブルシューティング

* **「Failed to fetch」エラーが出た場合:**
  Pythonサーバーが落ちているか、起動し忘れている証拠だ。ターミナルを確認して再起動しろ。ゾンビプロセスが邪魔している場合は、タスクマネージャーから `python.exe` をキルしろ。
* **Windowsパスの区切り文字について:**
  Windowsのパスはバックスラッシュ（`\`）とスラッシュ（`/`）が混在しがちだが、拡張機能側で両方に対応（正規表現で吸収）するように作ってあるから、俺の出力したパスがどちらでも気にせずボタンを押してOKだ。
* **Git操作が失敗する場合:**
  プロジェクトがGit管理されていないか、Push権限がない（他人のリポジトリ）可能性がある。ターミナルのログを確認し、必要ならオレンジのボタン（Gitスキップ）を使え。
